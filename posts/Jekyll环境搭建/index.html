Debian上面搭建Jekyll环境

安装Ruby和基础依赖

1
2

apt update && apt upgrade
apt install ruby-full build-essential zlib1g-dev
  • ruby-full: 完整的Ruby环境
  • build-essential: gcc、make等编译工具
  • zlib1g-dev: 供某些gem包编译使用

配置gem的用户安装路径

编辑~/.bashrc文件

1
2
3
4
5
6
7
8

nano ~/.bashrc
# 在文件尾添加下面两句
export GEM_HOME="$HOME/gems"
export PATH="$HOME/gems/bin:$PATH"

# 让配置生效
source ~/.bashrc

安装Jekyll和Bundler

1
2

# 现在用gem安装，因为已经配置好路径，不需要sudo
gem install jekyll bundler

1
2
3

# 验证安装
jekyll --version
bundler --version

创建并运行第一个Jekyll站点

1
2
3

jekyll new my-site 
cd my-site
bundle exec jekyll serve

打开浏览器访问http://localhost:4000应该就能看到默认的Jekyll博客

如果在局域网中部署，打算局域网内访问，则:

1
2

bundle exec jekyll serve --host 0.0.0.0
# 这样服务就会绑定到0.0.0.0，局域网内的设备就都能访问了。

命令里bundle exec的作用是使用当前项目Gemfile锁定的gem版本，保证环境一致。

Windows上面搭建Jekyll环境

Windows上面搭建Jekyll环境，有四种主流搭建方法:

原生安装(RubyInstaller): 最直接在Windows上运行，不需要其他虚拟环境

WSL(Linux子系统):需要在Windows中安装Linux子系统，避免一些Windows上的兼容性问题

Docker: 安装docker环境后使用，环境完全隔离无需配置Ruby环境，docker一键启动，环境一致性高，但需要懂一点docker知识

包管理器(Chocolatey): 类似Linux的apt，通过命令行一键安装。但需要先安装Chocolatey

原生安装(RubyInstaller)

  1. 下载安装包: 访问RubyInstaller for Windows官网，下载带有Devkit的最新版本

注意：这里版本选择下载，如果想使用jekyll-theme-chirpy这个主题的，版本就选择3.x的，最新的4.x版本与主题版本冲突

  1. 运行安装程序: 强烈建议使用默认安装路径，并务必勾选“Add Ruby executables to your PATH”选项。安装快结束时，必须勾选“Run ‘ridk install’…”选项，然后点击“Finish”。
  2. 配置MSYS2开发工具: 上一步后会自动弹出命令行窗口，直接按 Enter 键安装 MSYS2 and MINGW development toolchain（即默认选项 1）。这是成功安装后面插件的关键。
  3. 检查Ruby环境: 完成上面所有步骤后，新开一个命令行窗口，分别输入 ruby -v 和 gem -v，看到版本号就表示 Ruby 安装成功了
  4. 安装Jekyll和Bundler: 在命令行中执行下面的命令，它会自动安装 Jekyll 和它的依赖管理工具 Bundler。 
    1

     gem install jekyll bundler
  5. 验证安装: 输入jekyll -v，如果能看到Jekyll的版本号，就代表一切就绪。如果提示找不到，可以试试重启电脑，一般就能够解决问题
