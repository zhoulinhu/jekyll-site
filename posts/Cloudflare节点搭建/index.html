Cloudflare节点搭建

这是一种可用的免费节点搭建方案，基于Cloudflare的搭建方式。

最大特点三个：
1.免费、稳定、速度还行！
2.不需要服务器、不需要额外成本，甚至连域名都可以获取免费二级域名。
3.整个搭建过程从零开始，大约10分钟就能完成。
  同时由于依托于Cloudflare本身的网络基础，这套方案在稳定性和可用性方面，也远远优于传统的临时节点或不稳定方案
  相比于过去那些复杂、容易失效、需要频繁维护的方式，这种方案更像是一种“轻量级长期解决方案”：一次搭建，持续可用，几乎不需要额外折腾，非常适合个人用户或轻度使用场景

准备域名并托管到Cloudflare平台

注册一个免费域名，下方二选一，推荐第一种

  1. 获取DNSHE 的域名
  2. 获取DigitalPlat 的域名

注册并登录Cloudflare，然后将上面注册的免费域名托管到Cloudflare

Cloudflare上面搭建节点

创建KV空间

在Cloudflare左边菜单找到：存储和数据库 -> Workers KV -> Create Instance -> 创建命名空间名称 -> 点击创建。来创建一个KV空间以备后面对接

创建Pages

现在需要上传由CMliu开源的程序，源码是明文开源在GitHub上的可以获取查看。或者直接下载Pages的专属安装包。

在Cloudflare左边菜单找到：构建 -> 计算 -> Workers和Pages，右边点击创建应用程序 -> 开始使用 -> 找到’拖放文件’项的开始使用，取一个项目名称点击创建项目，然后将刚刚下载的专属安装包上传，然后点击部署站点，完成Pages创建。

  • 部署完成后在Worker和Pages页下找到才创建的Pages，点击进去，然后点击设置 -> 变量和机密位置点击添加 -> 变量名称填写ADMIN，值则为要创建节点的管理员密码，后点击保存。
  • 绑定KV命名空间，还是在上面设置下 -> 绑定位置点击添加 -> 选择KV命名空间 -> 变量名称填写KV，选择之前上面创建的KV命名空间进行绑定，然后点击保存
  • 在设置旁边找到点击自定义域，点击设置自定义域，把之前注册并托管到cloudflare的域名填入(例如：xxxx.ccwu.cc)，点击继续
  • 访问后台：访问https://xxxx.ccwu.cc/admin输入刚刚配置的管理员密码即可登录节点后台。

✨ 核心特性

  • 🛡️ 协议支持：支持 VLESS、Trojan、Shadowsocks 等主流协议，深度集成加密传输。
  • 📊 管理面板：内置可视化后台，支持实时配置修改、日志查看及流量统计。
  • 🛠️ 部署灵活：完整适配 CF Workers 及 CF Pages (GitHub / 上传)。
  • 🔄 订阅系统：内置自动订阅生成及混淆转换，适配主流客户端（Clash, Sing-box, Surge 等）。
  • ⚡ 性能加速：支持自定义 ProxyIP、SOCKS5/HTTP 链式代理及优选 API，优化网络延迟。
  • 🌐 多台适配：完美适配 Windows, Android, iOS, MacOS 及各种软路由固件。

可以使用常见的V2Ray客户端来进行导入代理节点，就可以使用Cloudflare搭建的免费节点。
