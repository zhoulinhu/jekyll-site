Conda是啥

Conda是一个跨平台、开源的包管理和环境管理系统，最初为Python程序创建，但现在能管理任何语言的软件包。

可以把Conda理解成”软件管家”+”隔离沙箱”的结合体，核心作用有两个：包管理器、环境管理器

包管理器(Package Manager)

帮助安装、更新、卸载软件包，并自动解决复杂的依赖关系

  • 多语言支持: 不限于Python包(如numpy)，也能装R包、C/C++库、甚至命令行工具。
  • 预编译包: 通常直接安装已编译好的二进制文件，省去自己从源码编译的麻烦，在Windows上尤其方便。
  • 多源选择: 除了官方默认源，还能使用社区源(如conda-forge)获取更丰富、更新的包

环境管理器(Environment Manager)

能创建彼此隔离的虚拟环境，每个环境可以拥有不同版本的Python和软件包，互不干扰。

  • 解决冲突: 比如项目A需要Python3.8 + TensorFlow 2.4，项目B需要Python3.11 + PyTorch 2.0，conda可以轻松创建两个独立环境，一键切换。
  • 环境可复现: 可以把当前环境的所有包以及版本导出成一个environment.yml文件，别人用这个文件就能立刻复现出完全相同的环境，保证结果一致。

和Pip的区别

  • pip只能管理Python包，而conda可以管理任何软件(包括Python解释器本身)。
  • pip从源码或wheel安装，依赖处理相对简单；conda会更严格地检查所有包的版本兼容性。
  • 通常用conda创建环境+安装非Python依赖，再用pip安装conda源里没有的Python包，两者可配合使用。

刚开始接触，安装Miniconda(只有命令行，体积小)或Anaconda(带图形界面和数百个预装数据科学包)就行。官方下载页: Conda

基本使用命令(从创建环境到共享环境)

  1. 配置conda-forge(强烈推荐先做)

    1
2

     conda config --add channels conda-forge
 conda config --set channel_priority strict

    这样装包时会优先使用conda-forge，包多、版本新

  2. 创建环境 
    1
2
3
4
5

     # 创建一个名为 myenv 的环境，同时指定 Python 版本
 conda create -n myenv python=3.11

 # 也可以创建时就装上一些包
 conda create -n my-ruby-env ruby=3.3 rails
  3. 激活/退出环境 
    1
2
3
4
5
6

     # 激活
 conda activate myenv       # Windows / Linux / macOS
 # 激活后命令行前会出现 (myenv)

 # 退出当前环境，回到base
 conda deactivate

  4. 管理包

     # 查看当前环境已安装的包

 # 在当前环境安装包（会自动解决依赖）
 conda install numpy pandas matplotlib

 # 安装指定版本
 conda install numpy=1.26.4

 # 更新包
 conda update numpy

 # 卸载包
 conda remove numpy

 # 搜索可用版本
 conda search numpy

  5. 环境快照与复现

    导出环境文件（给别人用）

    1
2

     conda activate myenv
 conda env export > environment.yml

      生成的environment.yml里记录了所有包及其精确版本。
      别人拿到后，只需要:

    1

     conda env create -f environment.yml

      就可以复现完全一样的环境。

    仅导出明确安装的包（不含依赖）

    1

     conda env export --from-history > environment.yml

      这种方式导出的文件更干净，只包含你显式安装的包，跨平台兼容性更好。

conda-cli命令使用

Conda的命令主要分为两类：

  • conda开头的(管理包、环境、配置等)
  • conda-env开头的(专门管理环境导出/导入，实际使用时会缩写成conda env)

🏞️ 环境管理

命令 作用 示例
conda create -n 环境名 [包...] 创建新环境 conda create -n myenv python=3.11
conda create -p 路径 [包...] 在指定路径创建环境（不一定要在envs目录下） conda create -p D:\projects\myenv python=3.9
conda activate 环境名/路径 激活环境 conda activate myenv
conda deactivate 退出当前环境 conda deactivate
conda env list (或 conda info --envs) 列出所有环境及其路径 conda env list
conda remove -n 环境名 --all 彻底删除某个环境 conda remove -n myenv --all
conda rename -n 旧名 新名 重命名环境（Conda 22.9+） conda rename -n myenv newname

📦 包管理（必须在激活的环境中操作）

命令 作用 示例
conda install 包名 安装包 conda install numpy pandas
conda install 包名=版本号 安装指定版本 conda install ruby=3.3.5
conda install -c 频道 包名 从特定频道安装 conda install -c conda-forge rsync
conda update 包名 更新某个包 conda update numpy
conda update --all 更新当前环境所有包（谨慎使用） conda update --all
conda remove 包名 卸载包 conda remove numpy
conda list 列出当前环境所有包 conda list
conda list -n 环境名 查看指定环境内的包 conda list -n myenv
conda search 包名 搜索可用的版本 conda search python
conda search -c conda-forge 包名 在特定频道搜索 conda search -c conda-forge ruby

🌐 频道与配置

命令 作用 示例
conda config --add channels 频道名 添加频道（自动排名靠后） conda config --add channels conda-forge
conda config --set channel_priority strict 设置频道优先级严格模式 同上
conda config --show channels 查看已添加的频道列表 conda config --show channels
conda config --remove channels 频道名 移除某个频道 conda config --remove channels conda-forge
conda config --show 显示所有配置 conda config --show

📄 环境快照与迁移

命令 作用 示例
conda env export > environment.yml 导出当前环境所有包（含依赖） 在激活的环境下运行
conda env export --from-history > environment.yml 仅导出用户显式安装的包 推荐用于共享，跨平台兼容性更好
conda env create -f environment.yml 根据文件创建环境 自动使用文件中的环境名
conda env create -f environment.yml -n 新环境名 用文件创建一个指定名字的新环境 conda env create -f env.yml -n myclone

🧹 日常维护

命令 作用
conda clean -a 清理所有缓存（下载的包、索引等），释放磁盘空间
conda clean --packages 仅清理未使用的包缓存
conda clean --tarballs 仅清理下载的 tarball 文件
conda info 查看 Conda 自身信息（版本、路径、Python版本等）
conda info -e 等同于 conda env list

Windows上Conda环境保存路径：默认统一放在安装目录下的envs文件夹里。
命令查看所有环境的准确路径: conda env list，注意自定义路径环境不会在该命令的名字列表里，只会显示路径。

Conda能安装那些库

类别 说明 典型例子(都可以用conda install安装)
Python 数据科学栈 Conda 的强项，预编译，避免C++编译器问题 numpy, pandas, scipy, matplotlib, scikit-learn, statsmodels
Python 深度学习/ML 含GPU支持，可精确控制CUDA版本 tensorflow, pytorch, keras, xgboost, lightgbm
Python Web开发 常见框架及工具 flask, django, fastapi, gunicorn, uvicorn, requests
Python Jupyter生态 交互式编程、笔记本 jupyterlab, notebook, ipython, jupyterlab-git, nb_conda_kernels
Python 通用库 爬虫、图像处理、测试等 scrapy, pillow, opencv, pytest, black, flake8
其他语言 R、Julia、Node.js、Rust、Go等 r-base, r-ggplot2, julia, nodejs, rust, go
系统/命令行工具 隔离环境内安装，不污染系统 git, curl, wget, make, cmake, ffmpeg, imagemagick, tree
数据库驱动 连接各种数据库 sqlite, mysql-connector-python, psycopg2 (PostgreSQL), pymongo
生物信息/科学计算 通过 bioconda 频道获取 samtools, bwa, blast, bowtie2, biopython
地理空间数据处理 GIS库 gdal, geopandas, shapely, fiona, rasterio
  • conda install不只可以装Python包，还可以装R包(如r-dplyr)、系统工具(如git)、字体(如font-ttf-dejavu-sans-mono)等。
  • 这些包绝大多数由社区维护在conda-forge, 少部分来自defaults(Anaconda官方源)
