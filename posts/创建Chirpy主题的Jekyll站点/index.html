创建Chirpy主题的Jekyll站点

这是一篇介绍搭建Jekyll站点的，使用它的jekyll-theme-chirpy主题，chirpy自带github的工作流，能够git提交后GitHub Actions自动构建部署，可以通过GitHub Pages公开访问。

使用Chirpy Starter模板(官方提供)

  1. 创建新仓库
    • 访问Chirpy Starter仓库
    • 点击绿色的“Use this template”按钮，然后选择“Create a new repository”
    • 给新建的仓库取名(如my-site)，然后点击”Create repository”
  2. 克隆到本地:
    • 在终端中，将刚刚创建的新仓库克隆到本地: 
      1
2

       git clone git@github.com:your-username/my-site.git
 cd my-site
  3. 安装依赖:
    • 在项目根目录下运行以下命令来安装所有必要的Ruby gem依赖: 
      1

       bundle install
  4. 运行网站:
    • 启动Jekyll本地开发服务器 
      1

       bundle exec jekyll serve --host 0.0.0.0
    • 现在，应该可以通过http://ip:4000来访问网站了

核心配置与个性化

  • 基本设置(_config.yml): 这是网站的全局配置文件，必须修改的参数包括:
    • url: 设置为你的网站最终访问地址，例如https://your-name.github.io
    • avatar: 你的头像图片路径。
    • timezone: 你的时区，例如Asia/shanghai。
    • lang: 网站的主要语言，例如 zh-CN
    • title 和 tagline: 网站标题和副标题
  • 联系方式(_data/contact.yml): 在这个文件中，可以修改并填写你的电子邮件、社交媒体等联系方式。
  • 写文章(_posts): 所有编写的Markdown文档文件放在这个文件夹下。
    • 添加新的文章，文件命名必须遵循YYYY-MM-DD-文章标题.md的格式，例如 2026-01-01-my-fisrt-post.md。
    • 文章的开头需要包含正确的YAML Front Matter。

配置GitHub Pages公开访问

已经通过Chirpy Starter创建了仓库，要让它通过GitHub Pages公开访问，重点是完成仓库设置和_config.yml的URL配置两步。

修改_config.yml的访问地址

在项目根目录找到_config.yml，按照仓库类型填写：

仓库类型 仓库名格式 url示例 baseurl
用户/组织站点 你的用户名.github.io https://你的用户名.github.io ""(空)
项目站点(最常见) 任意名字，比如myblog https://你的用户名.githb.io /myblog(带斜杠)

例如，你的Github用户名是zhangsan，仓库名叫my-blog，则:

1
2

url: "https://zhangsan.github.io"
baseurl: "/my-blog"

这是最容易出错的点, baseurl必须正确，否则网站所有CSS/JS链接都会断裂

启用GitHub Actions自动部署

Chirpy Starter已经自带了 .github/workflows/pages-deploy.yml工作流，只需在仓库设置中激活它。

  1. 进入github仓库 –> Settings –> Pages
  2. 在Build and deployment的Source下拉菜单中，选择GitHub Actions
  3. 页面会自动保存，不需要点击其他按钮

推送代码触发构建

将本地代码提交并推送到GitHub(通常是main分支):

1
2
3

git add .
git commit -m "initialize chirpy blog"
git push origin main

推送后：

  • 进入仓库的Actions选项卡，可以看到一个名为pages-build-deployment(或类似)的工作流正在运行
  • 等待它变成绿色 ✅，表示构建和部署完成

访问网站

构建成功后，网站地址就是：

1
2
3

https://你的用户名.github.io/仓库名
# 例如
https://zhangsan.github.io/my-blog
